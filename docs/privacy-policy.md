# PocketPad — Privacy Policy

**Last Updated:** April 2025

## Summary

PocketPad does not collect, store, or transmit any personal data. All communication occurs exclusively over your local network.

## Data Collection

PocketPad collects **zero** personal data. Specifically:

- **No analytics or telemetry** of any kind
- **No usage tracking**
- **No crash reporting** (unless you enable system-level crash reporting)
- **No user accounts or registration**
- **No cloud storage or sync**

## Local Network Communication

PocketPad uses Apple's MultipeerConnectivity framework to communicate between your iPhone and Mac:

- Communication occurs **only** over your local Wi-Fi network or Bluetooth connection
- Sessions are **encrypted** using MultipeerConnectivity's built-in encryption
- **No data is transmitted** to external servers, cloud services, or third parties
- Connection data (peer names) is held only in memory and discarded when the app closes

## Keyboard Input

- Text you type on the iPhone keyboard is sent **directly to your Mac** over the local encrypted connection
- Typed text is **never logged, stored, or transmitted** to any external destination
- Text exists only momentarily in memory during transmission

## Permissions

| Permission | Platform | Purpose |
|-----------|----------|---------|
| Local Network | iPhone | Discover and communicate with Mac over local network |
| Accessibility | Mac | Move cursor, simulate clicks, type text |
| Input Monitoring | Mac (optional) | Advanced keyboard event handling |

No other permissions are required or requested.

## Third-Party Services

PocketPad uses **no third-party services**, SDKs, or analytics frameworks.

## Data Retention

PocketPad retains only user preferences (sensitivity, acceleration, etc.) stored locally on each device using UserDefaults. No personal or identifying information is stored.

## Children's Privacy

PocketPad does not knowingly collect information from children under 13.

## Changes to This Policy

Any changes to this privacy policy will be communicated through app updates.

## Contact

For questions about this privacy policy, contact the app developer.
